# 9. قوالب حالات القوائم (List Status Templates)

المصدر: `apps/api/src/boards/board-templates.ts`،
`apps/api/src/boards/boards.service.ts` (دالة `create`)، والحقل `statusCategory`
في `apps/api/prisma/schema.prisma` و `packages/types/src/domain.ts`.

## الفكرة والدافع

في نموذج Kanban **حالة البطاقة هي القائمة التي تسكنها** (لا يوجد حقل "حالة"
منفصل). لتسريع بدء العمل، أُضيف **قالب جاهز** يُنشئ للوحة الجديدة خمس قوائم تمثّل
سير عمل قياسيًا للمهام، بدل أن يبنيها المستخدم يدويًا واحدة واحدة.

الحالات الخمس، بالترتيب:

| الاسم (بالعربية) | `statusCategory` |
|---|---|
| جديد | `NEW` |
| جاهز للتنفيذ | `READY` |
| قيد التنفيذ | `IN_PROGRESS` |
| بانتظار تقييم | `REVIEW` |
| تم التنفيذ | `DONE` |

## لماذا حقل `statusCategory` وليس الاسم فقط؟

اسم القائمة **قابل للتغيير ومترجَم**؛ لو اعتمدت التقارير على مطابقة الاسم العربي
"تم التنفيذ" لانكسرت عند أي إعادة تسمية. لذلك تحمل كل قائمة مُنشأة من قالب حقلًا
اختياريًا `statusCategory` (enum) يُبقي **المعنى** ثابتًا بمعزل عن الاسم — وأهمّه
الحالة النهائية `DONE` التي يعتمدها قسم التقارير لتحديد "المُنجَز" (انظر
[`11-reports.md`](./11-reports.md)).

- القوائم المُنشأة يدويًا (خارج القالب) تحمل `statusCategory = null`، وتُعامَل في
  التقارير على أنها **ليست منتهية** (not-done).
- الحقل حاليًا **إعلامي فقط** لأغراض التقارير؛ لا يفرض قيودًا على النقل بين القوائم،
  ولا يمنع تعديل اسم القائمة.

## متى يُطبَّق القالب؟

القرار المُثبَّت: **عند إنشاء اللوحة فقط**. يقبل طلب إنشاء اللوحة حقلًا اختياريًا:

```
POST /boards   { name, description?, template?: "EMPTY" | "TASK_WORKFLOW" }
```

- `EMPTY` (الافتراضي) — يحافظ على السلوك التاريخي: لوحة بلا قوائم.
- `TASK_WORKFLOW` — تُنشأ اللوحة **وقوائمها الخمس** داخل نفس عملية الإنشاء.

مواضع القوائم (`position`) تُولَّد دفعةً واحدة عبر
`generateNKeysBetween(null, null, 5)` من `@app/ordering`، فتأتي مفاتيح مرتّبة
وفريدة بترتيب الحالات (انظر [`06-ordering.md`](./06-ordering.md)). لا يوجد بذر
لأي بطاقات — القوائم فقط.

## التوسّع لاحقًا

القالب حاليًا **واحد مبني في الكود** (`TASK_WORKFLOW_TEMPLATE`). إضافة قوالب أخرى
تعني توسيع enum `BoardTemplate` في `packages/types` وإضافة مصفوفة قوائم جديدة في
`board-templates.ts`. القوالب القابلة لتخصيص المستخدم مؤجّلة.
